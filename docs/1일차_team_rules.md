## Git & Github Rules ### 

###1. 브랜치 규칙 main 브랜치에는 직접 push 하지 않기. 각자 작업 브랜치를 만들어서 작업하기 

### 2. 커밋 메시지 규칙
한 커밋에는 한 가지 작업만 담기
메시지는 한글로, 무엇을 했는지 알 수 있게 쓰기
예: feat: 로그인 화면 레이아웃 추가

### 3. 코드 리뷰
PR은 올린 당일 안에 확인하기
리뷰 코멘트는 "~하면 어떨까요?"처럼 제안하는 말투로 남기기
리뷰어가 승인(Approve)한 뒤에만 merge 하기
